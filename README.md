# TAIÓ — Dashboard Geoquímico

Painel geoquímico (Plotly + Leaflet, HTML autônomo) do sistema intrusivo de Taió (SC):
lista/mapa sincronizados, 41 amostras reais de geoquímica plotadas em 9 diagramas de
classificação, e um quadro de área/volume/classificação Ti por corpo intrusivo.

Abra `dashboard_geoquimico.html` direto no navegador.

Identidade visual TAIÓ — Sistema Intrusivo · Plumbing System. Complemento dos outros
produtos: [TPS_HUB](https://github.com/TPlumbingSystem/TPS_HUB) (página inicial),
[TPS_MOD3D](https://github.com/TPlumbingSystem/TPS_MOD3D),
[TPS_SEC2D](https://github.com/TPlumbingSystem/TPS_SEC2D),
[TPS_WEBM](https://github.com/TPlumbingSystem/TPS_WEBM).

Gerado por `gerar_dashboard_geoquimico.py` (Python, Plotly/GeoPandas) — depende dos
dados do projeto completo, não roda de forma standalone fora dessa estrutura;
incluído aqui como referência/histórico do código.
